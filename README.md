# Lab 4 — Task 2

This Java project adds three interfaces to the zoo class hierarchy.

- `AnimalBehavior` defines `sleep()` for `Dog`, `Pigeon`, and `Blowfish`.
- `AnimalMove` provides a default `move()` method. `Dog`, `Pigeon`, and `Blowfish` override it.
- `AnimalName` provides the static `name(String)` method to print each animal's name.
